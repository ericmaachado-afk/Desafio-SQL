# Desafio SQL - GrowMarket

Este repositório contém a resolução completa do desafio SQL utilizando o Olist Brazilian E-Commerce Dataset.
 
## Estrutura ## 
- Scripts SQL organizados por blocos (A até I).
- Cada consulta comentada com a pergunta de negócio.
- Insights principais documentados abaixo.

## Principais Insights ##
- **Estados com maior faturamento:** São Paulo lidera com certa folga, seguido por Rio de Janeiro e por ultimo Minas Gerais.
- **Categorias com pior reputação:** Telefonia e eletrônicos apresentam notas médias menores nas avaliações.
